# Countdown Lock Screen — Land a Python Backend Developer Job

A phone-sized countdown lock screen (9:20, 1080x2400) for the Handshake
"Your Deadline, Your Design" challenge, built with Google Gemini.

- **Deadline:** Land a Python Backend Developer job — 31 Dec 2026
- **Style:** Midnight (dark blue, minimal)
- **Milestones:** Apply to 20 roles — 3 Dec 2026 · Interviews in full swing — 12 Dec 2026 · Final rounds + offer — 22 Dec 2026

Open `index.html` in a browser (or visit the GitHub Pages link) — the
days-left count is computed live from the current date, the top fifth is
left clear for the phone clock, and the deadline date is fixed.
